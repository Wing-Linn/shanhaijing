# 山海经 · 上古奇书数字图书馆

> 《山海经》—— 中国上古地理志怪奇书，全书十八篇，记载山川道里、神灵异兽、方国部族、奇花异草，汇聚远古神话传说，是中华文明最古老的想象之书。

本项目将《山海经》原文以数字图书馆的形式呈现，提供篇章阅读、异兽图鉴、山川志探索与全文搜索等功能，配以典雅的水墨宣纸风格界面设计。

---

## 功能一览

### 首页

- 大幅书法标题与朱砂印章装饰
- 全书统计概览（篇章数、异兽数、山川数）
- 四部经书分类卡片（山经 / 海经 / 大荒经 / 海内经）
- 精选异兽展示
- 经典名句引用区

### 篇章目录

- 按四部分类展示全部 17 篇（原文缺"海内东经"一篇）
- 每篇显示节数、异兽数、山川数
- 点击进入阅读视图，展示该篇所有原文段落
- 段落末尾标注所载异兽与山川

### 异兽图鉴

- 收录 187 种异兽、神灵、方国部族
- 支持按名称、描述、形貌搜索
- 支持按篇章筛选
- 详情弹窗展示形貌、能力、出没地点、征兆等信息

### 山川志

- 收录 65 座山川
- 支持按山名、物产搜索
- 支持按篇章筛选
- 详情弹窗展示山川描述与所产之物（金玉、草木、异兽等）

### 全文搜索

- 跨篇章、异兽、山川三类内容全文检索
- 分类展示搜索结果，支持跳转到对应栏目

## 设计风格

- **配色**：米色宣纸底（`#faf7f0`）配墨色文字，朱砂红用于印章与异兽标题，青绿色用于山川，赭金色用于装饰线与统计数字
- **字体**：Noto Serif SC（正文/标题）、Noto Sans SC（界面文字）
- **动效**：淡入、上浮、缩放、微光等动画，卡片悬停上浮与阴影
- **响应式**：从手机到桌面全适配

## 关于《山海经》

《山海经》约成书于战国至汉初，作者不详，全书十八篇，分为四部：

- **山经**（五篇）：记述天下山川物产、神灵异兽
- **海经**（四篇）：记述海外四方异国异民、奇物怪事
- **大荒经**（四篇）：记述大荒之中神灵异兽、远古传说
- **海内经**（四篇）：记述海内四方山川神灵、方国部族

书中记载的夸父逐日、刑天舞干戚、精卫填海、大禹治水等神话故事，是中华文明最古老的想象之书，对后世文学、艺术、神话研究影响深远。
